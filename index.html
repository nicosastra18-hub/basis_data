BAGIAN 1: Data Definition Language (DDL) Nomor 1 - 2

Lengkapi klausa pembuatan database dan tabel berikut ini:

-- 1. Membuat dan Mengaktifkan Database
CREATE DATABASE sistem_perpustakaan_universitas;
sistem_perpustakaan_universitas;
-- 2. Membuat Tabel Mahasiswa & Relasi Foreign Key
CREATE TABLE mahasiswa (
  nim VARCHAR(15) ,
  id_fakultas INT,
  nama_mahasiswa VARCHAR(100) NOT NULL,
  status ('Aktif', 'Lulus', 'Cuti') DEFAULT 'Aktif',
  FOREIGN KEY (id_fakultas) fakultas(id_fakultas)
);
-- 3. Modifikasi Struktur Tabel (Menambah Kolom Baru)
ALTER TABLE mahasiswa nomor_telepon VARCHAR(15);
BAGIAN 2: Data Manipulation Language (DML) Nomor 3

Isi bagian kosong untuk manipulasi data (Insert, Select, Update, Delete):

-- Pengisian Data Baru
INTO fakultas (nama_fakultas) VALUES ('Fakultas Ilmu Komputer');
-- Pencarian Judul Buku dengan Wildcard
SELECT * FROM buku WHERE judul_buku '%SQL%';
-- Pembaruan Status Mahasiswa
UPDATE mahasiswa status = 'Lulus' WHERE nim = '2023003';
BAGIAN 3: Fungsi Agregat & Pengelompokan Nomor 4

Lengkapi query perhitungan statistik dan filter kelompok data:

-- Rata-rata, Nilai Maksimum, dan Nilai Minimum Stok Buku
SELECT
  (stok_tersedia) AS rata_rata_stok,
  MAX(stok_tersedia) AS stok_terbanyak,
  MIN(stok_tersedia) AS stok_tersedikit
FROM buku;
-- Pengelompokan & Penyaringan Jumlah Mahasiswa per Fakultas >= 2
SELECT id_fakultas, COUNT(nim) AS jumlah_mahasiswa
FROM mahasiswa
BY id_fakultas
COUNT(nim) >= 2;
BAGIAN 4: Penggabungan Tabel (JOIN & UNION) Nomor 5

Lengkapi klausa join untuk menghubungkan beberapa tabel:

-- Penggabungan Data Irisan Mahasiswa & Fakultas
SELECT m.nim, m.nama_mahasiswa, f.nama_fakultas
FROM mahasiswa m
JOIN fakultas f m.id_fakultas = f.id_fakultas;
-- Menggabungkan Dua Query (FULL OUTER JOIN)
SELECT m.nim, m.nama_mahasiswa, p.id_pinjam FROM mahasiswa m LEFT JOIN peminjaman p ON m.nim = p.nim

SELECT m.nim, m.nama_mahasiswa, p.id_pinjam FROM mahasiswa m RIGHT JOIN peminjaman p ON m.nim = p.nim;
BAGIAN 5: Pemicu Otomatis (Trigger) Nomor 6

Lengkapi bagian pengondisian trigger untuk stok buku:

DELIMITER //
CREATE TRIGGER trg_kurangi_stok
INSERT ON detail_pinjam
FOR EACH ROW
BEGIN
  UPDATE buku SET stok_tersedia = stok_tersedia - 1 WHERE id_buku = .id_buku;
END //
DELIMITER ;
